# UX/UI-редизайн FoodScan

## Направление до реализации

Нативный Compose-интерфейс для проверки пищевых продуктов. Главная ведёт к
сканированию; профиль и избранное доступны через постоянную навигацию.

Палитра сохраняет спецификацию: хвоя `#0B3D32`, мята `#E8F7EE`,
фон `#FAFBF8`, белый `#FFFFFF`, основной текст `#17201D`, вторичный `#66736D`.
Яркий зелёный используется только как небольшой акцент графики сканирования.
Системный SansSerif: заголовок экрана 28/36 semibold, действие 24/32 semibold,
заголовки секций 22/28, строки 16/24, подписи 14/20. Без новых шрифтов и библиотек.

Сравнены два варианта: сетка одинаковых карточек действий и вертикальный маршрут
«сканирование → сценарий → продукты». Выбран второй: сетка уравнивала важность
сканирования и вспомогательных функций. Вместо отдельных карточек продуктов —
единая поверхность списка. Все тексты выровнены слева, пустые состояния по центру.

```text
FoodScan
Состав и пищевая ценность
┌────────────────────────────┐
│   графика штрихкода         │
│   Сканировать продукт      │
└────────────────────────────┘
Обычное питание       Профиль
Недавно просмотренные
┌────────────────────────────┐
│ Овсяные хлопья             │
│ Натуральный йогурт          │
│ Цельнозерновой хлеб         │
└────────────────────────────┘
Избранное
Главная  Сканер  Избранное  Профиль
```

Проверка против brief: выразительность сосредоточена в сканировании, графика
связана со штрихкодами, а не с декоративным wellness-шаблоном. Нет градиентов,
рекламного текста, одинаковых карточек для каждого элемента или новых функций.
Сохраняются callbacks, маршруты, локальные примеры и честные заглушки.

Адаптация: прокрутка, ширина содержимого до 640 dp, рост элементов по тексту,
минимум 48 dp для действий, safeDrawing insets, подписи и heading-семантика.
Превью: узкий экран, шрифт 200%, планшет, пустое состояние, все разделы.
