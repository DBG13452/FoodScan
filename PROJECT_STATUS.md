# FoodScan — состояние проекта

Дата: 11.10.2026. Реализован этап 3; по запросу пользователя упрощён интерфейс перед следующим этапом.

## Результат

Вместо Hello Android открывается главный экран FoodScan: название, сценарий
«Обычное питание» со ссылкой «Открыть профиль» в компактном блоке,
крупная кнопка «Сканировать продукт», секция
«Недавно просмотренные», три демонстрационных продукта и переход в избранное.

Работают четыре маршрута Navigation Compose: Главная, Сканирование, Избранное,
Профиль. Нижняя панель отражает текущий маршрут; кнопки главной открывают нужные
разделы. Для вкладок настроены launchSingleTop, popUpTo/saveState и restoreState;
повторный выбор текущей вкладки не создаёт новую запись в стеке.

Главная использует фирменные цвета, типографику, FoodScanButton, FoodScanCard и
FoodScanSectionTitle. Экраны прокручиваются, учитывают отступы Scaffold и имеют
ограничение ширины 640 dp на широком экране. Нижняя панель остаётся вне прокрутки.
Иконки — четыре локальных векторных ресурса; тексты — в strings.xml.

## Архитектура и зависимости

- MainActivity отвечает за системные панели и запуск FoodScanTheme/FoodScanApp.
- ui/FoodScanApp.kt содержит Scaffold и NavigationBar.
- navigation/FoodScanDestination.kt описывает четыре фиксированных маршрута.
- navigation/FoodScanNavHost.kt связывает экраны и выполняет переходы.
- ui/home, ui/scanner, ui/favorites, ui/profile содержат экраны с callbacks.
- ui/home/HomeDemoProducts.kt — только модель представления названия/категории примеров.
- ui/components/FoodScanScreenColumn.kt задаёт общую прокручиваемую раскладку.

Добавлена одна прямая зависимость: Navigation Compose 2.9.8, исправленный релиз
ветки 2.9 ([официальное описание](https://developer.android.com/jetpack/androidx/releases/navigation#2.9.8)).
Переход на ветку 2.10 для текущих маршрутов не требуется. Новых Gradle-модулей,
плагинов сериализации, библиотек иконок и DI нет.

Остальные объявленные версии сохранены: Gradle 9.6.0, AGP 9.4.1, Compose plugin
2.2.10, BOM 2026.02.01; compileSdk/targetSdk 37, minSdk 26; JVM Gradle 25,
Java compatibility исходников 11. Транзитивные зависимости разрешает Gradle:
dependencyInsight подтверждает lifecycle-runtime 2.9.4 в debugRuntimeClasspath.
Это не изменение значения lifecycleRuntimeKtx в каталоге версий.

## Классификация Lint

Все перечисленные замечания имеют уровень warning в SARIF; ошибок и fatal нет.
Приоритет ниже — практическая оценка работ, а не изменение уровня Android Lint.

| Правило | Было в этапе 2 | Сейчас | Приоритет и смысл |
| --- | ---: | ---: | --- |
| GradleDependency | 6 | 7 | Плановое обслуживание: доступны новые версии библиотек; совместимость проверять перед обновлением |
| NewerVersionAvailable | 1 | 1 | Плановое обслуживание: есть новая версия Kotlin Compose plugin |
| RedundantLabel | 1 | 1 | Низкий: Activity повторяет label приложения, косметическая избыточность |
| UnusedResources | 7 | 7 | Низкий: оставшиеся шаблонные XML-цвета не используются |
| **Итого** | **15** | **16** | **Сборку не блокируют** |

Новое предупреждение GradleDependency относится к Navigation Compose 2.9.8:
Lint предлагает 2.10.2. Предупреждения об обновлении не являются доказательством
уязвимости или ошибки текущего приложения. Подавления Lint не добавлялись,
массовое обновление зависимостей не выполнялось.
